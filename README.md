# Planet Collection Roma

Landing page statica del negozio Planet Collection Roma, dedicata a costumi, maschere, accessori e trucco professionale.

## Panoramica

- Brand: Planet Collection Roma
- Dominio: planetcollectionroma.it
- Tipo: sito landing page statico
- Obiettivo: presentazione del brand, lead generation e contatti

## Struttura

- `index.html` – pagina principale
- `CNAME` – dominio personalizzato
- `assets/` – immagini e risorse del sito

## Come usare localmente

Apri semplicemente il file `index.html` nel browser oppure avvia un server locale:

```bash
cd "C:\Users\ACER\Documents\planetcollectionroma"
python -m http.server 8000
```

Poi visita:

- http://localhost:8000

## GitHub Pages

Questo progetto è pronto per essere pubblicato su GitHub Pages senza build step, poiché è un sito statico HTML/CSS.

Passaggi:

1. carica il repository su GitHub
2. attiva GitHub Pages dal branch `main`
3. usa il file `CNAME` per mantenere il dominio personalizzato
4. verifica che il dominio `planetcollectionroma.it` punti correttamente al provider
